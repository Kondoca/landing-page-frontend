# Landing Page Frontend

Projeto iniciante de front-end desenvolvido com o objetivo de praticar
HTML, CSS e JavaScript, com foco em layout e animações básicas.

## 📌 Objetivo do projeto
Este projeto foi criado para treinar a estruturação de páginas web,
estilização com CSS e aplicação de animações utilizando JavaScript
e a biblioteca GSAP.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock)

## ▶️ Como executar o projeto
1. Clone este repositório
2. Abra o arquivo `index.html` em qualquer navegador
