# Landing Page Frontend

Projeto iniciante de front-end desenvolvido com o objetivo de praticar
HTML, CSS e JavaScript, com foco em layout e animações básicas.

## 🌐 Visualização do projeto
O projeto está disponível online no link abaixo:

👉 https://kondoca.github.io/landing-page-frontend/

⚠️ Observação: a visualização do site fica melhor em computadores
(desktop), pois o projeto não é totalmente responsivo.

## 📌 Objetivo do projeto
Este projeto foi criado para treinar a estruturação de páginas web,
estilização com CSS e aplicação de animações utilizando JavaScript
e a biblioteca GSAP.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock)

## ▶️ Como executar o projeto localmente
1. Clone este repositório
2. Abra o arquivo `index.html` em qualquer navegador

## 📚 Observação
Este projeto foi desenvolvido apenas para fins educacionais.
Não possui vínculo com marcas reais.
